## Expected Outputs

### Ranking Consistency

For each scenario, the following ranking properties must hold:

1. **Stability Score Ordering**: Paths ranked by `stabilityScore` descending
2. **Support Score Tiebreaker**: When stability equal, use `coalitionSupport`
3. **Conflict Penalty**: High conflict paths penalized in ranking
4. **Determinism**: Same inputs always produce same ranking

### Comparison Consistency

Pairwise comparisons must satisfy:

1. **Transitivity**: If A > B and B > C, then A > C
2. **Consistency**: Comparison(A,B) = -Comparison(B,A)
3. **Stability Basis**: Comparisons based on coalition stability metrics

### Selection Consistency

Winner selection must satisfy:

1. **Top Rank**: Winner is always rank 1 in ranked paths
2. **Stability Threshold**: Minimum 60 stability score for recommendation
3. **Conflict Check**: No unresolved critical conflicts
4. **Confidence Floor**: Minimum 0.5 confidence for selection

### Consensus Determination

Consensus levels calculated as:

| Level | Support Ratio | Description |
|-------|---------------|-------------|
| Unanimous | ≥ 85% | All members aligned |
| Strong | 65-84% | Clear majority |
| Moderate | 45-64% | Simple majority |
| Weak | 25-44% | Plurality only |
| Fractured | < 25% | No clear direction |

### Explanation Requirements

Each scenario output must include:

1. **Summary**: One-line coalition assessment
2. **Details**: Member-by-member evaluation
3. **Reasoning**: Why coalition dynamics exist
4. **Strengths**: Key alignment areas
5. **Conflicts**: Identified tensions
6. **Negotiations**: Recommended discussions
7. **Alternatives**: Other paths to consider

